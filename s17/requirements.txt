# Country Explorer — Exam Project

## What to Build
A web app that lists countries from the ApiCountries API (https://www.apicountries.com/) with search, filtering, dark/light theme, and a detail page.

## Tech Stack
- React + TypeScript (Vite)
- shadcn/ui
- Tailwind CSS
- React Router
- React Context (for theme + data)

## API Info
- Endpoint: GET https://www.apicountries.com/countries
- Returns: Array of country objects
- Key fields: name, capital, region, population, area, flags, languages, currencies, borders, alpha3Code, nativeName, demonym, timezones, subregion
- region values (for continent filtering): Africa, Americas, Asia, Europe, Oceano

## Routes
- / — Home: country list with search bar + continent filter buttons + theme toggle
- /country/:code — Country detail page (:code = alpha3Code)

## Features

### 1. Dark/Light Theme (React Context)
- Create a ThemeContext with a provider
- Store theme state ("light" or "dark")
- Toggle .dark class on the <html> element
- Persist choice to localStorage so it survives reload
- Put a Sun/Moon toggle button in the navbar

### 2. Country Data (React Context)
- Create a CountryContext that fetches all countries once on app load
- Store the array + loading/error states
- All pages consume this context (no repeated API calls)

### 3. Search
- Text input that filters countries by name or capital (case-insensitive)
- Filter happens client-side on the already-fetched array

### 4. Continent Filter Buttons
- Buttons for: All, Africa, Americas, Asia, Europe, Oceano
- Active button gets a different style
- Combine with search — both filters work together

### 5. Country Card
- Shows: flag image, country name, capital, region
- Clicking it navigates to /country/:alpha3Code
- Use shadcn Card component

### 6. Country Detail Page
- Reads :code from the URL
- Finds the country in the context data
- Shows: flag, name, capital, region, subregion, population, area, languages, currencies, bordering countries, timezones
- Has a "Back" button to return to the list
